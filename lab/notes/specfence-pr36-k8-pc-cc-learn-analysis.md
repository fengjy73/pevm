## 0. 总论：PR36 做了什么，以及现在什么还没做好

### 0.1 先回答用户要的那句

**S-lazy 4–25× 肥尾已经收干净。** 全集 Soft=0 N=3：`n≥512` 且 SF/OCC≥4× 的块从 PR34 的 5 个变成 **0**；倍数 max 从 27.45× 掉到 **3.61×**（`14396881`）；p90 从 3.31× 掉到 2.29×。PR34 K8 里那三条 S-lazy 代表链（`14396881` / `15274915` / `13217637`）暖机 `pick_occ` 从 ≈0 回到数百～一千，begin 洞从 26–95 收到 5–8。

**剩余最慢不是「同一条 S-lazy 尾巴没割完」，而是三类叠在一起：**

1. **Spine-U 还在，而且仍是墙冠军。** `19807137` Instant-off reuse **54.8 ms / 13.3 ms ≈ 4.1×**。storage 571 写者盖不住，unf 一直 246–595。PC 宽度已经在（暖机 `pick_occ` 1956–2561），败在 Detect / 臂宽，不在发行开关。
2. **中档真脊 Detect + n<512 过预付，是新的主剩余。** 扫块绝对墙 Top5 里，除 Spine-U 外全是 n=341–430 的 mixed 脊：`19434587` / `19606599` / `19716145` / `19860366`。它们的 `pick_occ` 已经是数百，但 begin 洞 49–108（P2 的 n≥512 cap 罩不住），`end_block` 2.1–4.3 ms 直接加在墙上。这不是 S-lazy 对象错误，是 **真脊上 Detect 过预付 + 串行尾**。
3. **S-lazy 残留是 2.7–3.5× 的壳，不是 25× 的模式开关。** `14396881` 仍是倍数第一（扫块 3.61× / Instant-off 3.47×），但 OCC abort 只有 3–5，`end_block` 0.3–0.5 ms，暖机 `pick_occ` 通常 766–1069。失败从「整块离开 OCC pick」变成了 **近独立肥块上的 SF 调度壳**。

所以：C1/P1 那一刀打中了 PR34 写的因果链。全集 PRIMARY 不再是「lazy 当锁链 → pick_occ=0」。下一刀如果还拿 S-lazy 当唯一北极星，会空砍；该分治 Spine-U 与中档过预付。

### 0.2 并行计算（PC）——目标与本尖端现实

**目标:** 在 W 核上压 makespan：依赖链走关键路径，**反链宽度吃满核**；独立工作零 SF 调度税。

**PR36 实际做了什么**

- P1 落地：闸是边约束，不是全局模式。K8 暖机 `pick_occ` / `occ_pick_while_gated` 从 PR34 的 ≈0 变成与 n 同量级（S-lazy 千级、中档 300–600、Spine-U 两千）。
- P2 落地：n≥512 的 begin 洞被 soft-cap 到个位数（`19807137` 恒 8，`14396881` 0–5，`15274915` 5–8，`13217637` 恒 8）。PR34 的 95 洞过预付在肥块上消失。
- P3 落地：肥 + lazy-seen 的 `end_block` 从 PR34 的 1–3 ms 收到 0.3–0.5 ms。
- Soft=0 仍在：K8 Instant-off / 扫块 `soft_wait_arms` 全 0，不用挂起填核。

**没做好什么（本轮 K8 共性，但不再是「整块关宽度」）**

- **宽度回来了，makespan 没有回到 OCC。** 暖机 `pick_occ ≫ 0` 只证明「未闸能走 OCC 索引」；它不证明 SF 调度壳、validate 旁路、`end_block` 串行尾为零。`14396881` 是干净反例：几乎无冲突（OCC abort 个位），宽度在，仍 3.5×。
- **P2 按 n≥512 切，漏掉了真正最慢的中档。** `19716145`（n=341）begin **102–108**，`19860366`（n=430）begin **76–78**。这些洞是真脊预付，不是 lazy 星，但效果一样：把可并行前缀压成等待图。
- **P3 只削了肥 lazy 尾。** 中档块 `end_block` 仍 2.1–4.3 ms，占 OCC 墙的 20–45%，与 8 核无关。`19860366` 暖机 end 3.85–4.29 ms，本身就够解释很大一块 2.3×。
- `ready_width` 仍常是 0/1：袋不深。税在控制流和串行尾，不在「核不够」。

### 0.3 并发控制（CC）——目标与本尖端现实

**目标:** 对真冲突边 Detect→有序或廉价 Resolve；对可交换 / lazy 不当事务锁链。

**PR36 实际做了什么**

- C1：`basic_lazy` / lazy writer chain 不再是 OrderedAdmit 对象。S-lazy 代表块不再为 900–1200 个 lazy 写者种 95 个洞。
- C2：真 Basic / storage 仍走轻覆盖。`15274915` 的 Basic 77 脊还在被闸（begin 5–8，oa 17–27），不再和 lazy 千级写者绑成一张预付图。
- C3 写了「禁止 Full 硬刚超长 storage」。产品路径上 Spine-U 的 begin 被 cap 到 8，没有再种 571 洞。
- 扫块不再出现 PR24 级 abort 列车当主杠杆。`19469101` 扫块 1.97× / 14.3 ms，活着。

**没做好什么**

- **C1 禁的是「lazy 当锁链」，没有禁「近独立肥块付 SF 壳」。** `14396881` 结构仍是 `basic_lazy` 1197，OCC 当廉价重叠，SF 即使不种洞也比 OCC 贵 3.5×。对象修正完成了半截：不再锁错链，但 Detect/调度路径对「几乎无边」的块仍过重。
- **C3 没有挡住嘴去选 Full/Seg。** `19807137` Instant-off 臂轨迹 `Full → Full → Win_1 → Win_2 → Opt → Seg_2 → Seg_3`。begin 洞是 8，但 oa 升到 800–1050，unf 从未低于 246。盖不住的真脊上，换臂 ≠ 换对象；Detect 强度不够，Resolve 列车还在（SF abort 900–1200，OCC 也 700–1200）。
- **中档真脊过预付。** `19716145` / `19860366` / `19434587` / `19606599` 的 begin 49–108 是真 Basic/storage 候选被种成洞。OCC abort 与 SF abort 同量级（不是「SF 幻觉冲突」），但 SF 额外付了洞上的 stall + `end_block`。这里 Detect 集合不过近似——它看到的是真脊——败在 **预付比 OCC 的 abort 更贵**。
- commute 在 K8 Instant-off 几乎全 0。中档 / Spine-U 的税不是 commute，是 Detect 列车和预付。
- 局部 unf 低仍不能当赢：`14396881` unf 3–7、dp 0，墙 3.5×。指标错位从「lazy 上灭 unfenced」换成「近独立块上灭 unfenced」，代理目标还是没对齐 OCC 墙。

### 0.4 学习——目标与本尖端现实

**目标:** 用墙后果更新 ĉ，让臂收敛到「整脊墙最小」；冷探热用；形态可迁移。

**PR36 实际做了什么**

- L1：lazy bucket 不该再继承 3356896 的 Win_2。S-lazy 代表块暖机不再钉死 Win_1 当「对 lazy 有序」。
- L2：不该靠抬 `w_need` / sys-reexec 去灭 lazy 上的 unfenced。`14396881` / `13217637` 的 `w_need` 多留在 0，dp 基本 0。
- L3：热 sticky 对 lazy 不再坚持有序。Instant-off 上 `14396881` 多数 iter 是 Opt，最后才滑到 Full。

**没做好什么**

- **嘴还是会在 lazy-morph 上选出 Full。** `14396881` Instant-off 末两 iter `Full`；PROFILE 上甚至 **7/7 Full**。L1 没有把「对此 morph 永不有序」学成稳定不动点。
- **真脊上的代理目标仍是灭 unfenced / 升窗。** `19807137` 从 Full 爬到 Seg_3，unf 从 595 降到 ~290 就停了，墙从 35 ms 冷启动涨到 55 ms 暖机——学习在用更贵的臂换一个仍然很高的 unf。`19860366` 爬到 Win_7 / `w_need=8`，墙没有掉。
- **中档块臂在 Win_* / Opt / Defer / Seg 之间摆，没有收敛。** `19716145`：`Win_1, Win_1, Win_2, Opt, Defer, Win_5, Win_1`。这不是探索到 Opt 更便宜就停，是危机 / leftover 把高预付臂一次次请回来。
- PROFILE Instant idle 仍会改轨迹（`19606599` PROFILE i=2 墙 408 ms、sched 桶 2.3e9 ns——**只标 Instant-tax，不当墙**）。分析以 Instant-off 为准。

### 0.5 一句话因果链（PR34 → PR36）

```
PR34: D1/学习把 basic_lazy 标成热 ℓ
        → Win/Defer/Full + begin 种洞
          → has_any_gated 贯穿 → pick_occ≈0
            → 整块 SF 壳 + 肥 end_block
              → 4–27×

PR36: C1 拆掉 lazy 对象
        → P1 恢复 OCC pick，P2 砍肥块 95 洞，P3 削 lazy end_block
          → S-lazy 掉到 2.7–3.5×（壳，不再是模式开关）
            → 墙冠军让位给 Spine-U（盖不住）
              与 n<512 中档真脊（P2 不管 + end_block 2–4 ms + 过预付）
```

## 1. 块 `19807137` — Spine-U（墙冠军，不是 S-lazy）

**一句话:** 真 storage 571 脊；PC 宽度已在，CC 盖不住，学习越学越贵。

| 口径 | OCC med | SF reuse | × | Soft |
|------|--------:|---------:|--:|------|
| 扫块 N=3 | 15.47 | 52.58 | 3.10 | 0 |
| Instant-off N=7 | 13.331 | **54.794** | **4.11** | 0 |
| PR34 Instant-off | 17.590 | 64.7 | 3.7 | 0 |

- 臂: `['Full', 'Full', 'Win_1', 'Win_2', 'Opt', 'Seg_2', 'Seg_3']`
- unf: `[595, 321, 246, 253, 278, 296, 292]`
- begin: 恒 **8**（P2 cap；PR34 是 38）
- pick_occ 暖: **1956–2561**（PR34 是 0–3）
- end_block 暖: 0.61–0.71 ms
- prepaid 暖: 1.17–6.91 ms
- SF abort: 901–1204 · OCC abort: 695–1273（同量级真冲突）
- 结构: L=571 W=106 indep=0.13；storage 1006 / basic 745 / lazy 12；顶脊 storage 571

> Instant-off OCC i=0 出现 2254 ms 尖刺，中位数仍用 13.331。尖刺不当墙。

### 并行计算：做了什么 / 没做好

**做了什么。** P1 在这条块上是真的：有闸时未闸仍 OCC pick，暖机两千次。P2 把 38 洞收到 8。8 核硬件宽度被用上了——OCC 自己也只要 ~13 ms，bound@8 只有 1.25，这条脊本来就窄。

**没做好。** 宽度不是杠杆。OCC 已经在付 700–1200 abort 的真冲突；SF 在同一冲突上再付调度壳 + 0.6 ms 串行尾 + 最高 6.9 ms prepaid。PC 视角的剩余是 **Resolve 列车把核浪费在重做上**，不是「没发行」。再加核、再开 OCC pick，都不会让 571 长链变短。

### 并发控制：做了什么 / 没做好

**做了什么。** 没有再把 571 写成 Full(571) 洞阵；begin 8 说明有序对象被 cap。真 storage 脊仍在 C2 路径上，没有被 C1 误判成 lazy。

**没做好。** 这是本轮 **CC 主败**。Win_1 / Win_2 / Seg_2 / Seg_3 都盖不住：unf 地板约 250。oa 从 55 爬到 1000+，abort 不降。C3 的精神是「不要用 Full 硬刚超长 storage」——嘴却还在选 Full 和 Seg。Detect 强度不够：短窗盖不住，长窗付不起。OCC 用同一套冲突只付 abort，墙仍是 SF 的 1/4。这里的下一刀是 **真脊覆盖策略（分段、或承认 OCC 在这条 L=571 上更便宜）**，不是再禁 lazy。

### 学习：做了什么 / 没做好

**做了什么。** 臂在动，说明 leftover / unf 危机还在喂嘴。sys-reexec 后期到 2，dp 到 1，闭环活着。

**没做好。** 奖励在「降 unfenced」。unf 595→250 时墙 35→55 ms——冷启动 Full 反而更便宜，暖机越学越贵。没有学到「对此 morph，有序预付 > OCC abort」。Seg_3 是高预付臂被危机请回来，不是收敛。

### 本块结论

**不是 S-lazy 残留。** 与 PR34 同类、同块。PC 刀已经打完。优先刀：Spine-U 分治（覆盖或让位 OCC），禁止再拿 Full/Seg 当唯一反应。

### 并行计算：做了什么 / 没做好

**做了什么。** 暖机 pick_occ 400+。臂已经是 Opt，PC 没有被 Win 钉死。

**没做好。** 54 个洞 + 2.5 ms `end_block` 在 Opt 下仍然在。Opt 不是「零 SF 税」；它只是不选有序臂。对 n=367、W=261 的块，2.5 ms 串行尾 ≈ OCC 墙的 20%。P3 没削这条尾（不是肥 lazy）。

### 本块结论

学习已经相对克制。剩余是 **Detect 默认洞 + end_block**，不是臂。下一刀不是再调 UCB。

## 4. 块 `19716145` — n=341，洞 108（P2 盲区标本）

**一句话:** 最干净的「P2 按 n 切」反例：真脊、中等 n、洞比肥 S-lazy 还多。

| 口径 | OCC med | SF reuse | × | Soft |
|------|--------:|---------:|--:|------|
| 扫块 N=3 | 9.72 | 26.10 | 2.22 | 0 |
| Instant-off N=7 | 10.147 | **20.340** | **2.00** | 0 |
| PR34 扫块 | 9.53 | 25.84 | 2.29 | 0 |

- 臂: `['Win_1', 'Win_1', 'Win_2', 'Opt', 'Defer', 'Win_5', 'Win_1']`
- unf: `[45, 28, 29, 21, 17, 35, 20]`
- begin: **102–108**
- pick_occ 暖: 293–369（仍 >0，但相对 n=341 被洞吃掉一块）
- end_block: 2.07–2.37 ms
- prepaid: **3.84–6.12 ms**
- refuse: 44–96
- dp: 0–2 · sys: 0–3
- 结构: L=46 W=226；顶脊 basic 46 + 多条 25 写者 basic/storage；lazy 只有 10

### 并行计算：做了什么 / 没做好

**做了什么。** Soft=0，pick_occ 仍有 300。没有回到 PR34 的「整块离开 OCC」。

**没做好。** **108 洞是本轮 K8 的 begin 峰值**，比 PR36 之后任何 S-lazy 肥块都多。P2 的谓词是 n≥512，本块 n=341 直接免检。prepaid 4–6 ms 已经接近 OCC 墙的一半。这是 PC 发行层的设计漏洞，不是测量噪声。

### 并发控制：做了什么 / 没做好

**做了什么。** 对象是真脊（basic 46 / storage 25），C1 没有误伤。dp 小，不是双付主导。

**没做好。** 对一条 L=46 的脊种 100+ 洞，是过预付。OCC abort 108–125，SF abort 104–173——冲突规模两边看见的差不多，SF 多付的是洞上的 stall。Detect「正确但太贵」。

## 11. 下一刀假设（仍是分析，不改代码）

按杠杆，不是按顺手：

1. **洞 cap 改谓词（PC+CC）。** 不要 `n≥512`。用 `begin_blocked` 上限或 prepaid 墙，覆盖 `19716145`（108）/ `19860366`（76）/ `19434587`（50）。这是本轮最干净的结构漏洞。
2. **`end_block` 从肥 lazy 推广到中档真脊（PC）。** `19860366` 4 ms、`19606599` 2.5 ms 是单时钟。P3 的 lean 条件太窄。
3. **Spine-U 分治（CC）。** `19807137` 与 S-lazy 不是一把刀。要么分段覆盖，要么承认 OCC 在 L=571 上更便宜，禁止 Full/Seg 当默认危机臂。
4. **近独立瘦路径（PC 壳）。** `14396881` / `13217637` 宽度已在，2.7–3.5× 是路径税。需要一条「lazy / indep≈1 时少走 SF 壳」的产品路径，而不是再禁对象。
5. **学习代理对齐 OCC 墙（Learn）。** 真脊上禁「unf 还高就升 w_need」；lazy-morph 上硬挡 Full。PROFILE Instant 继续不准进 ĉ。
6. **不要做的：** 再加宽有序去追 3356896；为 `15274915` 的 unf 把 95 洞请回来；把 SF≤OCC **计数** 当北极星（全集 28/98 vs PR34 22/98，52 集 9/52，计数不是本包赢面）。
