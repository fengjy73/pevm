# Soft=0：远程 Ideal-ready 先于晚波，墙和 SF−Ideal 没有下来

**日期：** 2026-09-24（北京时间）
**二进制：** `f2e3344`。测量在这一版上跑。后面的文档提交不改变二进制。
**起点：** PR #56 尖 `65e3609`。本刀是新 PR，不追加进 #56 的正文。
**块：** 15274915 为主。3356896 对照。Ideal `L_crit` 大块 **1.19 ms**（锁定）。SF−Ideal = SF − 1.19。
**协议：** Soft=0 Instant-off，release，LTO off，请求 8 核，宿主 4 核，`taskset -c 0-3`。大块 N=5，薄块 N=3。复用中位是去掉冷启动后 `sorted[len/2]`（四次复用取第三，两次取较慢的那次）。`SPECFENCE_COMPARE_CHECK=1`。主墙不设 `SPECFENCE_IDEAL_PROXIMITY_DIFF`。

## 结论

**门是 FAIL-A。** 两轮无探针大块复用中位是 SF **7.760** 和 **7.914**。同机关掉本刀（回到 #56 段内 Ideal-timed）是 **7.147** 和 **7.730**。同机再关掉 Ideal-timed、只留下下标段，是 **7.412**。QuietExit 锚是 **7.065** / SF−Ideal **5.875**。刀开的 SF−Ideal 是 **6.570** 和 **6.724**，没有低于同机对照，也没有低于锚。`ge_1_5=false`。

这不是只改了名字。非脊核在自己的 Ideal-ready 空了之后会先偷别的核的 Ideal-ready，再弹本核晚波。末轮 `steal` 是几百，不是 0。可见性变了，墙没有降。

探针（不入锁定）fill@1.19 是 **9.9%**，#56 是 **8.6%**。中位进入 **2.976 ms**，#56 是 **2.727 ms**。进入没有提前。1149 笔干净 Indep 的主 blocker 仍是 Admit。

薄块第一轮复用中位 **2.893**，相对同机下标段 **1.567** 和 #56 刀关 **1.421**，落到换核气费那一档（1.421→2.442）里。第二轮是 **1.856**，抬得少一些。薄块门不能算过。

单独看，离 ≥1.5 还远。不宣称 ≥1.5。锁定带 7.0–7.2 / 5.3–5.9 不换。

## 机制

`SPECFENCE_GLOBAL_IDEAL_READY_POOL` 默认开。名字还是池，实现不是单池。

- **下标段保留。** Worker 0 弹低端，其余核弹自己段的高端。`tx % C` 不回来。
- **弹的顺序。** 本段 Ideal-ready，然后偷远程 Ideal-ready，然后本段 `local_late`，最后才再平衡晚波。没有段内按气费重排，没有跨核 gas LPT。
- **`=0`。** 回到 #56：本段 Ideal-ready，再本段晚波，远程 Ideal-ready 只在两者都空之后才偷，自由核气费不齐时本段重的先弹。
- **两个旗都 `=0`。** 只有下标段，没有晚波拆分。这是 #56 笔记里的「刀关」形态。
- **SpineHop / Ordered** 仍是 `mark_wait` / Handoff，不进 AdmitIndep。Handoff 仍先于 Indep。`spine≤1`。ExactWake 仍只在真 publish tip。

单池在 `eeb3e37` 上测过，然后拿掉。那只二进制的大块复用中位是 **8.104**，当时刀关 **7.901**，双关分段 **7.866**。SF−Ideal **6.914**。薄块 **1.656** / 刀关 **1.544**。fill@1.19 **9.4%**，中位进入 **2.890**。`seq≡par` 会抖。把低前缀只留给 worker 0 的那一版会挂：链头先被 worker 0 拿走，低前缀没有别的核能弹。那些数不是本刀的门。
