# Soft=0：Ideal-timed AdmitIndep 没有把墙或 SF−Ideal 收下来

**日期：** 2026-09-24（北京时间）
**二进制：** `6516f6d`。测量在这一版上跑。后面的文档提交不改变二进制。
**基线：** PR #55 尖 `14b3f3d`。本刀是新 PR，不追加到 #55。
**块：** 15274915 为主。3356896 对照。Ideal `L_crit` 大块 **1.19 ms**（锁定）。薄块对照 **0.031 ms**（`specfence-per-tx-vs-parallel-bound`）。
**协议：** Soft=0 Instant-off，release，LTO off，请求 8 核，宿主 4 核，`taskset -c 0-3`。大块 N=5，薄块 N=3。复用中位是去掉冷启动后 `sorted[len/2]`（四次复用取第三，两次取较慢的那次）。`SPECFENCE_COMPARE_CHECK=1`。主墙**不**设 `SPECFENCE_IDEAL_PROXIMITY_DIFF`。

## 结论

**这刀不是真 makespan。门是 FAIL。** 两轮无探针大块复用中位是 SF **8.268** 和 **7.627**。同机把刀关掉是 **7.399**。锁定带仍是 **7.0–7.2 / 5.3–5.9**。SF−Ideal 分别是 **7.078** 和 **6.437**，锚是 **5.875**（带 5.81–6.01），没有收缩。`ge_1_5=false`。

这不是 #53 那种 rename。两轮的 span 和 join 没有稳定地「span 变长、join 变短、墙不动」。墙本身没有下降，SF−Ideal 没有变小。探针把干净 Indep 的首次 `execute` 放在 Ideal 就绪（t≈0）之后：中位进入 **2.73 ms**，到 `L_crit` 1.19 ms 只填了 **8.6%**。

## 机制

`SPECFENCE_IDEAL_TIMED_ADMIT` 默认开。设 `0` / `false` 回到原来的下标分段。

- **分段不动。** AdmitIndep 仍按连续下标切到各核。Worker 0 的段高索引先压、LIFO 先弹出低前缀。其余核从自己段的高索引端开始。`tx % C` 会把每核都送进前缀，15274915 在 2 核上出过错收据。
- **Ideal-ready 先于晚波，但只在同一段里。** 已有 Detect 前驱的交易进 `local_late`，等这段的 Ideal-ready 双端队列空了再弹。偷取也是先 Ideal-ready，再晚波。脊 Handoff 仍先于两者。`spine≤1`。ExactWake 仍在真 tip。
- **自由核段内，气费不齐时重的 Ideal-ready 先弹。** 交易留在原来的段上，不换核。
- **做过、已拿掉的换核 LPT。** 把自由核上的交易按气费重新分到别的核，薄块同机墙从 1.421 抬到 2.442，大块 `seq≡par` 也更不稳。那一版没有留下。

Detect 和 WaitOnce 仍看真 tip。没有 Estimate 门，没有 park-all，没有 frame-suspend，没有加核。
